# Code of conduct

Be kind and assume good faith. This project deals with consumer hardware and
several Linux audio stacks; reports that are incomplete or "obviously wrong"
are still someone's real experience.

Unacceptable behaviour includes harassment, personal attacks, discriminatory
language, and publishing other people's private information (including
Bluetooth MAC addresses without permission).

Maintainers may edit or remove comments, close issues, or block accounts that
violate these expectations. Report concerns privately through a GitHub security
advisory or by contacting a maintainer.

This is a small hobby project. Disagreement about technical decisions is fine;
contempt is not.
